# Clipboard history

Status: implemented for Todo `1cc487d1b2ad4a92b5bf02c32e798f7c`.

Implemented `dots clipboard` on the shared Python controller with native Bash/PowerShell dispatch. Reuse `clipboard.py`; record only successful copies when `apps.clipboard.record_copies` is enabled (default false). The optional watcher starts explicitly, polls at a configurable interval and exposes start/stop/pause/resume/status. No boot autostart, live watcher activation, package installation or clipboard test against the user's data accompanies implementation.

Use a private platform-state SQLite store, atomic SQL transactions, secure-delete and no retained clipboard-content backups. Reads/help/completion never initialize it. Stable UUID entries contain UTF-8 text, source, created/updated time and pin state. Defaults: 500 entries, 30-day unpinned retention, 64 KiB per entry, deduplication enabled, 2-second polling; pinned entries survive age/count pruning but count toward a hard storage bound. Explicit remove/clear/import/export are scoped; deletion preview/review revalidates exact IDs and revisions. Local storage is not encrypted and secure deletion cannot guarantee physical erasure from snapshots/flash. Import validates the full batch before changing anything.

Expose browse/list/search/show/add/capture/copy/print/insert/pin/unpin/remove/clear/prune/export/import/status/pause/resume and watch start/stop/pause/resume/status. Exact raw/JSON output is separate from sanitized human previews. CLI metadata derives from one static grammar; native completion reads stable IDs without accessing the clipboard or starting services. No additional standalone command.
