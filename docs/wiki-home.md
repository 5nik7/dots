# Dots

Dots manages dotfiles, shells, themes, platform profiles and repository workflows across Termux, Linux, WSL and native Windows. This wiki is generated from documentation maintained with the implementation.

## Start here

1. Begin with [Dots core](core.md) and [installation](installation.md): what Dots owns, safe setup and recovery.
2. Find a task in [commands](commands.md), [managed files](files.md), [Git](git.md) or [Todo](todo.md).
3. Understand [configuration](configuration.md), [environment variables](shell-environment.md), [profiles](profiles.md) and [shell startup](shell-init.md).
4. Explore [themes](themes.md), [Neovim](neovim.md), [tmux](tmux.md), [Anodize](anodize.md), [packages](packages.md) and [fonts](fonts.md).
5. Use [keybindings](keys.md), [weather](wttr.md) and [debugging](debug.md) for everyday reference and diagnosis.

## Find your way around

The sidebar groups everyday tasks, shell setup, themes, tools, reference material and contributor guides. `dots wiki` provides the same navigation in your terminal; `dots wiki search 'config precedence' --topics` searches current source topics offline, and `dots wiki browse --query 'nvim themes'` opens matching sections. Ordinary `dots wiki search QUERY` retains literal search of local exported pages.

Native runtime evidence and platform limits are recorded in [platforms](platforms.md) and [PowerShell](powershell.md). Proposed features are labeled explicitly. Read [safety and recovery](safety.md) before managed changes.
