# Dots

Dots manages dotfiles, shells, themes, platform profiles and repository workflows across Termux, Linux, WSL and native Windows. This wiki is generated from documentation maintained with the implementation.

## Start here

1. Read [installation](installation.md) for checkout setup, previews and recovery.
2. Browse [commands](commands.md), [managed files](files.md) and [Git workflows](git.md).
3. Configure [shell startup](shell-init.md), inspect [environment values](shell-environment.md) and understand [profiles](profiles.md).
4. Explore [themes](themes.md) and [Anodize](anodize.md).
5. Use [debugging](debug.md) and [testing](testing.md) when diagnosing behavior.

## Find your way around

The sidebar groups everyday tasks, shell setup, themes, tools, reference material and contributor guides. `dots wiki` provides the same navigation in your terminal; `dots wiki search QUERY` searches the local exported pages.

Native runtime evidence and platform limits are recorded in [platforms](platforms.md) and [PowerShell](powershell.md). Proposed features are labeled explicitly. Read [safety and recovery](safety.md) before managed changes.

## Improve these pages

Edit the canonical source using `dots wiki edit PAGE`, then build and check the wiki. See [wiki maintenance](wiki.md). The generated command reference comes from first-party static command metadata; optional/private extensions are not exported.
