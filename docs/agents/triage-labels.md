# Triage labels

Each role uses the same label name in GitHub Issues.

| Role and GitHub label | When to use it |
| --- | --- |
| `needs-triage` | A maintainer needs to evaluate the issue. |
| `needs-info` | The reporter needs to supply more information. |
| `ready-for-agent` | The issue is specified well enough for an agent to implement independently. |
| `ready-for-human` | The issue needs human implementation. |
| `wontfix` | The maintainer has decided against taking action. |
